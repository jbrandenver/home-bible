# Home Bible — project notes
## Accessibility

Accessibility is a non-negotiable product requirement. Invoke and follow the accessibility skill for all user-facing UI work. Target WCAG 2.2 Level AA unless a project-specific requirement is stricter. Accessibility must be incorporated during implementation and tested before a feature is considered complete.

See `docs/accessibility/` (standard, engineering guide, testing, release checklist, jurisdiction matrix). Do not claim a product is "100% ADA compliant" or certified; we target and test against WCAG 2.2 AA.
